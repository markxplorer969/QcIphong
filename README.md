# Generator Gambar QC iPhone 📱

Sebuah website *single-page* sederhana yang memungkinkan pengguna untuk membuat gambar percakapan (Quality Check) palsu dengan tampilan antarmuka seperti iPhone. Proyek ini dibuat murni menggunakan **HTML, CSS, dan JavaScript** di sisi klien, tanpa memerlukan *backend* atau *database*.

![Contoh Tampilan Website](https://qciphong.markxplorer.my.id/og-image.jpg) 

## Deskripsi 📝

Alat ini dirancang untuk kemudahan penggunaan, di mana semua kode (HTML, CSS, dan JavaScript) digabungkan menjadi satu file `index.html`. Pengguna dapat mengisi berbagai parameter seperti teks pesan, waktu, warna, dan jenis font untuk menghasilkan gambar percakapan yang unik. Website ini berinteraksi langsung dengan API publik untuk memproses dan menghasilkan gambar.

## Fitur ✨

- **🎨 Kustomisasi Penuh:** Atur teks, waktu, nama sinyal, warna *bubble chat*, warna menu, warna teks, dan jenis font.
- **📥 Unduh Langsung:** Tombol "Download Gambar" akan muncul untuk menyimpan hasil gambar ke perangkat Anda.
- **🚀 Desain Modern:** Antarmuka pengguna (UI) yang bersih, responsif, dan dibuat dengan *dark mode* yang menarik.
- **🌐 Footer Informatif:** Footer minimalis yang berisi tautan ke sosial media (Instagram, TikTok, GitHub, WhatsApp), portofolio, dan *source code* proyek.
- **🧩 Single File:** Seluruh kode proyek berada dalam satu file `index.html` untuk portabilitas dan kemudahan penggunaan.
- **🔍 SEO Friendly:** Dioptimalkan untuk mesin pencari dengan meta tags, Open Graph, dan Schema Markup.

## Teknologi yang Digunakan 💻

- **HTML5:** Untuk struktur dasar dan konten website.
- **CSS3:** Untuk styling, layout (Flexbox/Grid), animasi, dan desain responsif.
- **JavaScript (ES6):** Untuk logika dinamis, interaksi dengan API, dan manipulasi DOM.

## Cara Menggunakan 🚀

Karena ini adalah proyek *front-end* murni, Anda tidak memerlukan server atau instalasi yang rumit.

1.  **Clone atau Unduh Proyek:**
    ```bash
    git clone https://github.com/markxplorer969/QcIphong.git
    ```
    Atau cukup unduh file `index.html` dari repositori.

2.  **Buka File:**
    Cukup klik dua kali pada file `index.html` untuk membukanya langsung di browser favorit Anda (Google Chrome, Firefox, dll).

3.  **Mulai Membuat:**
    Isi formulir sesuai keinginan Anda dan klik tombol "Generate Gambar".

## Referensi API 🔗

Proyek ini menggunakan API publik gratis dari **anabot.my.id** untuk menghasilkan gambar.

- **Endpoint:** `https://anabot.my.id/api/maker/iqc`
- **Metode:** `GET`
- **Parameter:** `text`, `chatTime`, `statusBarTime`, `signalName`, `bubbleColor`, `menuColor`, `textColor`, `fontName`, `apikey`.

*Catatan: Proyek ini menggunakan `apikey=freeApikey` sesuai dengan ketentuan penyedia layanan.*
